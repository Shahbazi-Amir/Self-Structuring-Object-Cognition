# نقشهٔ دانشی SSOC

این پوشه یک نمای دیداری از آرشیو پژوهش است. هدف آن حذف یا بازنویسی یادداشت‌های اولیه نیست؛ هدف، جداکردن مسیرهای قابل‌آزمایش از ایده‌های دوربرد و حفظ پیوند هر نتیجه با منبع اصلی است.

## شروع سریع در Obsidian

1. برنامهٔ Obsidian را جداگانه نصب کنید.
2. نسخهٔ محلی مخزن را با `Open folder as vault` باز کنید.
3. فایل [[docs/knowledge_map/SSOC_Project_Map.canvas]] را باز کنید.
4. برای دیدن ارتباط یادداشت‌ها، Graph View را باز کنید.

تنظیمات شخصی `.obsidian/` عمداً وارد مخزن نشده تا تنظیمات هر کاربر و سیستم به پروژه تحمیل نشود.

## شیوهٔ خواندن

- «آرشیو» یعنی محتوای اصلی که نباید حذف شود.
- «فرضیه» یعنی ایده‌ای که هنوز نتیجه محسوب نمی‌شود.
- «قابل‌آزمایش» یعنی ورودی، خروجی، معیار موفقیت و حالت شکست آن قابل تعریف است.
- «دوربرد» یعنی ممکن است الهام‌بخش باشد، اما فعلاً وارد هستهٔ مهندسی نمی‌شود.
- «رد در شکل فعلی» یعنی ایده حذف نشده؛ فقط با تعریف فعلی قابل دفاع یا قابل سنجش نیست.

## وضعیت این مرحله

فهرست‌برداری فایل‌ها، سلول‌های غیرخالی، موضوع‌ها، تکرارهای آشکار، چند تعارض محوری و فاصلهٔ ادعا تا کد انجام شده است. استخراج و برچسب‌گذاری تک‌تک ادعاها، نتیجه‌گیری‌ها و زنجیره‌های استدلال هنوز مرحلهٔ بعد است.
