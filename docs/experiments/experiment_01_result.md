# نتیجهٔ آزمایش ۰۱ — هستهٔ بدیهیات عقلی ۰٫۱

تاریخ اجرا: ۲۰۲۶-۰۸-۱۲

## نتیجه

| سامانه | نتیجهٔ درست | کل | دقت در مجموعهٔ کنترل‌شده |
|---|---:|---:|---:|
| هستهٔ ۰٫۱ | ۱۲ | ۱۲ | ۱۰۰٪ |
| خط پایهٔ بدون زمان/زمینه | ۸ | ۱۲ | ۶۶٫۷٪ |

هسته چهار خطای خط پایه را رفع کرد:

- `C03`: تفاوت زمان را تناقض اعلام نکرد.
- `C04`: تفاوت زمینه را تناقض اعلام نکرد.
- `C05`: با زمان ناقص، نتیجه را نامعین اعلام کرد.
- `C06`: با زمینهٔ ناقص، نتیجه را نامعین اعلام کرد.

## کنترل‌های فنی

- ۹ آزمون نرم‌افزاری عبور کرد.
- ۱۲ سناریوی داده‌ای ازپیش‌ثبت‌شده ارزیابی شد.
- API و CLI هر دو خروجی JSON ساختاریافته تولید کردند.
- نصب editable بسته بدون وابستگی اجرایی خارجی موفق بود.
- بررسی syntax و whitespace خطایی نشان نداد.

## تفسیر مجاز

نمایش صریح زمان و زمینه در این جهان کوچک، از داوری بیش‌ازحد قطعی جلوگیری کرد و از خط پایه بهتر بود.

## تفسیر غیرمجاز

این نتیجه نشان نمی‌دهد که هسته فهم عمومی، فطرت، خودآگاهی یا توان یادگیری دارد. مجموعهٔ آزمون کوچک و طراحی‌شده برای همین قابلیت محدود است. نتیجهٔ ۱۰۰٪ فقط دربارهٔ همین ۱۲ مورد صدق می‌کند.
