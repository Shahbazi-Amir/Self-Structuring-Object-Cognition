# واژه‌نامهٔ عملیاتی هستهٔ بدیهیات عقلی ۰٫۱

این واژه‌نامه معنای اصطلاح‌ها را فقط در محدودهٔ آزمایش مهندسی نسخهٔ ۰٫۱ تعیین می‌کند. این تعریف‌ها ادعای نهایی فلسفی یا دینی نیستند.

| اصطلاح | تعریف عملیاتی در نسخهٔ ۰٫۱ |
|---|---|
| هسته | سامانه‌ای قطعی برای نگهداری گزاره‌های کنترل‌شده و داوری دربارهٔ تناقض مستقیم |
| ابژه/موضوع | شناسهٔ چیزی که گزاره دربارهٔ آن است |
| نسبت | رابطه یا ویژگی‌ای که میان موضوع و محمول بیان می‌شود |
| محمول/متعلَّق | چیزی که نسبت به آن اعمال می‌شود |
| گزاره | ترکیب صریح موضوع، نسبت، محمول، قطب، زمینه، زمان و منشأ |
| قطب | اثبات (`affirm`) یا نفی (`deny`) یک ساختار معنایی |
| هویت معنایی | برابری موضوع، نسبت و محمول پس از نرمال‌سازی فنی |
| وحدت دامنه | یکسان‌بودن صریح زمینه و زمان دو گزاره |
| تناقض مستقیم | هویت معنایی و دامنهٔ کاملاً یکسان، همراه با قطب مخالف |
| سازگار | در زوج‌های موجود تناقض مستقیم یا ابهام دامنه یافت نشده است |
| نامعین | قطب‌ها مخالف‌اند، ولی زمینه یا زمان برای احراز وحدت دامنه کافی نیست |
| نامرتبط | موضوع، نسبت یا محمول دو گزاره متفاوت است؛ دربارهٔ روابط غیرمستقیم داوری نمی‌شود |
| منشأ | شناسهٔ منبعی که گزاره از آن وارد حافظه شده است |
| ردّ داوری | شناسهٔ دو گزاره، نتیجه، کد دلیل و توضیح قابل‌خواندن |
| فهم | در نسخهٔ ۰٫۱ تعریف یا اثبات نمی‌شود؛ فقط قابلیت‌های لازم برای یک داوری محدود آزموده می‌شوند |
| بدیهی | نامزد نظریِ اصل یا محتوای اولیه؛ نسخهٔ ۰٫۱ فقط اصل عدم پذیرش تناقض مستقیم را عملیاتی می‌کند |
| فطرت | منبع الهام و پرسش فلسفی پروژه؛ در نسخهٔ ۰٫۱ مؤلفهٔ نرم‌افزاری نیست |

## تمایزهای الزامی

- «نفی یک گزاره» با «نبودن اطلاعات دربارهٔ آن» یکسان نیست.
- «تفاوت زمینه یا زمان» با «تناقض» یکسان نیست.
- «نبود زمینه یا زمان» با «برابری آن‌ها» یکسان نیست.
- «پاسخ درست آزمون» به‌تنهایی شاهد فهم نیست.
- «اصل کنترل‌کننده» لزوماً یک «معنای ازپیش‌موجود» نیست؛ این رابطه هنوز پرسش باز پروژه است.
